# 公民的声音

**为什么今天可以不听它、我们为此在做什么、以及它可能生长成什么**

> 本文件展开《宣言》的一项规定。第六条说，Earthlings 人民形成其 earthlings 可核实的集体立场，并把它传达给各国和各国际组织，而这一立场的力量不取决于人民的权限，而取决于人的自由参与、程序的透明和验证结果的可能。
>
> **这里所写的一切都不是承诺。** 人民之所以存在，是因为人把它创立了起来，而不是因为前面有种种可能。

---

## 本文件的地位

**本文件不设定任何东西。** 它不创设权利，不课加义务，不授予权限，也不限制权限，不许可任何事，也不禁止任何事。文集中任何其他文件的任何一项规定都不以它为依据，也不得以它为依据。

**它作说明，也作推想。** 文集中其余的文件描述已经存在的东西，或者设定应当如此的东西。本文件也谈论尚不存在之物：谈论那些台阶——至今一级也没有走完；谈论那些可能性——其中没有一种被承诺过。第十八节列举了这一切可能落空的九种方式，第十九节则说明哪些已经建成、哪些还没有。

**具有拘束力的是《宣言》和宪章。** 出现不一致时适用它们，而不一致通过修改本文件来消除。对本文件的解释，既不得降低对人的保障，也不得扩大人民或者它任何机构的权限。

**它可以被整个改写或者撤回，而这不会改变任何东西。** 《宣言》、宪章、名册、投票的程序以及人们彼此之间的归属，都将保持原样。作推想的文本，不应当背负任何会随着落空的推想一同垮掉的东西。对它的建议与对其余一切文件的建议同等受理（[创立期](https://earth-lings.org/documents/zh/zh20-the-founding-period.html)）。

# 第一部分　失灵

## 第一节　渠道很多，计数没有

人们习惯说，人没有办法被听见。这话不准确，而这种不准确妨碍看清真正的问题。今天把意见传上去的渠道，比任何时候都多：请愿、给议员的信、公开听证、对法案草案公开征求意见的程序、社交网络、每周的民调。渠道过剩。缺的是**证明**：有多少签名是活人签的，民调究竟问了谁，两百万条评论是不是人写的。

请注意这种反驳的构造。它**不在实质上争论**：它不说“你们错了”，它说“不知道你们是否存在”。而这就足以不作答复而又不失体面：收件人并没有否定人们的意见，他是对证明表示了怀疑，而怀疑看上去像谨慎，不像轻慢。

正因为如此，公民的声音才是可以被忽略的。不是因为权力邪恶，而是因为**计数失灵了**。二〇一七年美国联邦通信委员会举行的法定公开评论程序中，两千两百多万条评论之中将近一千八百万条是伪造的——这是纽约州总检察长办公室二〇二一年五月六日公布的调查所确定的，而争论的双方都在伪造。贬值的不是那些伪造：贬值的是**全部两千两百万条**，包括真实的那些，而任何国家的任何机关都由此获得了一个正当理由，去根本不相信公众的输入。

往后还会更糟，而这与任何人的恶意无关：制造像模像样的人类文本，不论多少都已经变得便宜，而仅凭文本本身把它同人写的区分开来，很快就会做不到。剩下还能分辨的，**不是文本，而是它的来源**：这段表达背后是否有一个经过验证的、活着的、唯一的、自愿表达的人。而这正是 Earthlings 人民会做的事。

## 第二节　五种失灵

失灵有五种，性质各不相同，而我们的工具并不打中全部五种。

**汇总。** 选举把一个人多种多样的看法压缩成几年一次的一个选择，而社会就某一个单独问题的立场根本没有表达。**视野。** 后果在三十年后显现的决定，是由视野只到下一次选举的人作出的；那些还不投票的人和那些还没有出生的人，在世界上任何一个政治体系之中都没有代表。**领土。** 气候、跨国利润的征税、人工智能的规则、大流行病、海洋与大气，都不是在一个国家的边界之内解决的，而国家之间的协调停滞不前：没有谁因为达成了国际共识而被重新选上。**对输入的信任崩塌。** 真实的公众输入已经同制造出来的无从分辨，而贬值的恰恰是真品。**组织的不对称。** 二十家公司，每一家押着一亿，组织起来很容易；两千万公民，每人押着一百元，组织起来则不可能，而集中的利益几乎总是战胜分散的利益，与谁有理无关，也与政体形式无关（曼瑟·奥尔森《集体行动的逻辑》，一九六五年）。

由此得出其余一切所立足的结论：**分散的多数之所以落败，不是因为人少，也不是因为它没有理，而是因为它聚起来太贵。** 凡是能极大降低聚集成本的东西，都会改变结局。五种失灵、联邦通信委员会的案件以及奥尔森的分析，见附件[《为什么计数失灵了》](https://earth-lings.org/documents/zh/zh02a-why-the-count-is-broken.html)。

## 第三节　这是构造，不是阴谋

五种失灵没有一种是出于恶意造成的。代表制是在别无他法的时候被发明出来的：数以百万计的人在物理上无法不经中介去讨论公共事务，而诚实地清点他们的票也没有办法做到。它起过作用，也取得了很多成就。只有一件事它没有做到：它没有给人一种自己表达共同意志的办法。

《世界人权宣言》第二十一条说，人民的意志应当是政府权力的基础；《公民权利和政治权利国际公约》第二十五条确认每个公民参与公共事务的权利；《联合国宪章》以“我联合国人民”开篇。权利得到了承认，而据以直接行使它的程序却没有——一项得到承认、却无人可以主张的权利，仍然是一条得不到适用的规范。我们不认为有谁应当受责备。我们认为，当年之所以不能做到的那个原因，已经消失了。

# 第二部分　我们在建造什么

## 第四节　不是渠道，是仪器

**我们建造的不是又一种发声的方式。我们建造的是一台测量仪器。**

差别是根本性的。渠道传送消息；今天渠道有几十种，再加一种什么也不会改变。仪器确立事实：如此这般数目的经过验证的唯一的人，就某个问题作出了如此这般的回答，而且这可以被复核。

> 一场运动争取的是让人被**听见**。Earthlings 人民所做的，是让人被**计算**——用一种连不喜欢这个结果的人也能复核的方式。

今天，每个人都可能被听见。被计算的，一个也没有。

紧接着就是一句不说不行的话，因为这个词是危险的。**仪器是一套程序，而不是人。** 被测量的不是人：人按自己的意愿回答或者不回答，而回答属于他自己。我们所说的仪器，是收集并验证回答的程序——问题、期限、名册、签名、公布。人民不是任何人的工具，包括不是它自己的工具：工具是它建造的，不是它本身。否则就会与[《宣言》](https://earth-lings.org/documents/zh/zh01-declaration.html)第三条相抵触，那里说人的尊严不可侵犯，而人不是手段。

## 第五节　让人无法忽略的工具所具有的五项性质

“让人没法不注意我们”这个课题，世界上已经解决过许多次。下面五项属性，是从对没有权限的影响的案例分析中得出的——各种指数与排名、被终止的《营商环境报告》排名、政府间气候变化专门委员会、互联网的标准、爱尔兰的公民大会、罗素法庭；分析见附件[《没有权限的影响》](https://earth-lings.org/documents/zh/zh02b-influence-without-powers.html)。具备全部五项属性的工具，忽略它的代价很高；哪怕缺一项，忽略它就不费分文。

**性质之一。它产出所需要的、而且别处再也拿不到的东西。** 不是“重要的意见”，而是数据或者程序——缺了它们，有人就没法工作。

**性质之二。程序完整可见。** 不只是结果，还有它是怎样得到的：谁在提问，问题怎么说，谁可以回答，多少人回答了，怎样核实计数。什么都看得见的时候，就没有什么可争的。

**性质之三。它定期运作，而且前后可比。** 一次性的测量是新闻；每年用同样的方法测量同一个问题，就是一个序列，而序列显示变动，人们不得不把变动考虑在内。

**性质之四。各方同样地使用它。** 只对一方有用的工具是武器，人们会连同那一方一起把它否定掉。对双方都有用的工具是基础设施，双方都会爱惜它。

**性质之五。构成可核实。** 已知并且可以验证：测量背后站着活着的、唯一的人，其中每一个都表达过一次，而且是自愿的。

**第五项性质我们有，而且据我们所知别人都没有**——民意调查公司没有，请愿平台没有，社交网络没有，国家在自己的选举之外也没有。不披露身份的唯一性验证，正是护照和名册为之而建的东西，也是这套构造之中唯一不重新建造一遍同样的东西就无法复制的部分。**前四项性质我们目前还没有。** 它们不需要发明——它们是被遵守的：这是纪律的问题，而纪律可以从外部检验。

# 第三部分　测量是怎样构造的

没有它们测量就不成立的那些要求，由[宪章](https://earth-lings.org/documents/zh/zh05-charter.html)第八条之一规定：谁无权批准问题，什么与结果一同公布，谁决定是否存在缺陷，以及不得用谁的钱进行测量。详细的程序，宪章交由全体大会决定，并要求在第一次测量之前公布；截至今日尚未通过。下面是同样的内容，并说明每一项要求从何而来，以及在还没有规则的地方是怎样的构想。

## 第六节　谁参与

参与的可以是 earthling 护照的持有人——也就是通过了身份验证并在名册中取得了不可转让记录的人。这给测量带来什么：

- **一人一票**，因为一个人只有一本护照，而且护照不得转让；
- **一票不得被购买**，因为护照不可转让，也不得让渡；
- **一票不得累积**，因为财产与一票由[《宣言》](https://earth-lings.org/documents/zh/zh01-declaration.html)第十一条的不可修改的核心相分离；
- **任何人都可以核实**，因为名册活在区块链上，而不在我们的服务器上，并且可以直接从公开的智能合约中读出。

要紧的是这一点：**唯一性的验证并不要求披露身份。** 仪器知道记录背后站着一个活着的人，却不知道他是谁。对测量来说这就够了，对监视来说则不够。身份验证是怎样构造的、它为什么不变成监视，见[生物特征验证](https://earth-lings.org/documents/zh/zh16-biometric-verification.html)和[SBT 护照](https://earth-lings.org/documents/zh/zh15-sbt-passport.html)两份文件；这套基础设施之中哪些是开放的、哪些是封闭的、今天在哪些地方还得相信我们，见[我们现在在哪里](https://earth-lings.org/documents/zh/zh32-where-we-are-now.html)。

## 第七节　问题从何而来

这是任何测量之中最脆弱的地方，因而也是要求最严的地方。谁拟定问题，谁就决定了一半的答案：“您是否同意为了气候而多付电费？”和“您是否同意由污染者为损害付费？”——这是同一个问题，只是问法使答案变得相反。只要有一处诱导性的表述被公开发现，就足以使这次测量、以及过去和将来的一切测量一同贬值。

因此，问题的形成程序必须满足五项要求：

1. **分离。** 表述不由从事人民日常管理的人核定。这是两双不同的手。
2. **提前公布。** 问题在投票开始之前公布，并注明可以对它提出异议的期限。
3. **对抗阶段。** 表述要经过预期答案对其不利的那一方的异议。异议及对异议的答复与问题一同公布。
4. **开始之后不得变更。** 自投票开放之时起，问题不再修改。发现表述有缺陷，意味着取消这次测量并重新进行，而不是中途修补。
5. **与参与者生活的联系。** 问题被提在后果落到人身上的地方，而不是提在各机构就它达成协议的地方。这项要求不是为了对读者客气：它决定测量是否成立，下面另有说明。

问题的对象由[《宣言》](https://earth-lings.org/documents/zh/zh01-declaration.html)从两个方面限定。第三条划出范围：人民就涉及所有人的事情发表意见。第五条设置例外：个别国家的内部生活不是人民决定的对象，那是该国公民的事。

界线本身是封闭的，问题的清单则不是。落入其中的，例如有：跨国利润的征税、人工智能系统的规则、大气与海洋的命运、对大流行病的韧性、对后代所负的责任。个别国家的内部政治则一概不落入其中——这一点在第十节另行说明。

### 问题必须关系到被问者的生活

这是对最可能导致失败的原因——投票率低（第十八节）——的回答。它不靠提醒、也不靠号召来医治，而靠问题。**如果问题不关系到人们真实的生活、利益和困难，投票的意义就整个消失了：既没有必要问，也没有必要答。**

这里的矛盾是真实的：界线挑出的是全球性的问题，而全球性的东西听上去离人很远。它只是看上去远——全球性的问题**总要落到某个地方**，否则它就不是全球性的。所以它应当提在落地的那一点上，而不是提在谈判的那一点上：

| 提在谈判的点上 | 提在落地的点上 |
|---|---|
| 跨国利润的最低税率应当是多少 | 在您的国家经营的公司，是否应当可以在任何地方都不缴税 |
| 人工智能系统的监管制度应当是什么样的 | 人是否应当始终知道自己是在同机器说话，而不是在同人说话 |
| 地球共同资源的治理原则是什么 | 污染造成的损害应当由谁付费——是造成污染的人，还是住在旁边的人 |

右边和左边是同一个问题；右边的提法更准确，因为它指出了后果实际发生的那个地方。

**而界线紧接着就来，因为从这个手法到出事只有一步之遥。** 我们这样区分：**如果表述指出后果落在哪里，它是允许的；如果它提示应当如何看待这个后果，它是不允许的。**“公司是否应当可以在任何地方都不缴税”——这是指出。“大公司靠您发财却不缴税，这公平吗”——这是提示。两种提法都关系到生活；第二种不构成测量，而对抗阶段之所以存在，也正是为了筛掉这样的表述。

第二道界线是第五条：离人最近的问题几乎总是国内政治的问题，正因为如此它们才被排除在外。合用的问题处在两个条件的交集上：**它关系到人的生活，同时又没有国别的地址。**

### 问题分两条队列，而两条都需要

人们之所以作答，还有第二个原因：**回答会起作用。** 因此问题分两列排队，而且不得以一列取代另一列。

**人民内部生活的问题**——共同资金花在什么上、会费是多少、支持哪些项目、规则如何变更。这里的后果总是立即发生，而正是这些投票养成作答的习惯，习惯则是长距离上维持投票率的唯一依靠。它们的对象由[《宣言》](https://earth-lings.org/documents/zh/zh01-declaration.html)第九条限定：这是人民生活的问题，不是人民对外立场的问题。

**全球性问题**——就是上面所说的那些。它们的后果没有保证：我们可以测量并且公布，但不能承诺有人会作出答复。

由此得出一项意向，我们把它写在这里，好让人可以拿它来要求我们：**没有任何一个时期只由全球性问题构成。** 一个连年只就无人答复的事情投票的人民，会不再投票——而且它是对的。

## 第八节　两个层：审议小组与人民

这里我们回答针对整件事的最有力的反对意见：**就一个复杂问题去问数以百万计未经准备的人，并不比问一千个未经准备的人更好，它只是规模更大。**这条反对意见是成立的：规模本身并不带来判断的质量。对它的回答是[宪章](https://earth-lings.org/documents/zh/zh05-charter.html)第八条之二所确立的双层结构；今天还无法适用它——从只有几百人的名册中抽签得不出人民的横截面，而该条对此有明确的规定。

**第一层——审议小组。** 就每一个问题，由抽签从名册中选出一个审议小组。抽签没有意见：它给出的是人民的一个横截面，而不是人民之中活跃的那一部分，这一点是根本性的——活跃的那一部分总是有偏。审议小组用若干周时间把问题弄清楚：领取材料，听取专家和对立立场代表的意见，公开讨论。到最后审议小组并不作决定——它**拟出各种方案**，并陈述支持和反对每一种方案的理由，连同参与者没有取得一致的地方。

**第二层——人民。** 全体人民面对着审议小组的工作成果，就已经准备好的方案投票。

公民大会有深度而没有规模，公民复决有规模而没有深度；最接近把二者结合起来的尝试，见附件[《没有权限的影响》](https://earth-lings.org/documents/zh/zh02b-influence-without-powers.html)。而名册对别人的实际价值也在这里：**一个抽签的备选池**，从中抽样的随机性不被任何人质疑，而这样的抽签对任何一方同样适用。

## 第九节　与结果一同公布什么

没有痕迹的结果是一项断言。带着痕迹的结果是一项事实。因此每一次测量都连同核实它所需要的一切一同公布：

- 问题的逐字表述和各个答案选项；
- 问题公布的日期、投票开放和关闭的日期；
- 在对抗阶段提出的异议，以及对异议的答复；
- 审议小组的材料：按遴选方式列出的成员构成、研读过的文件、听取过的各方、陈述过的理由、被记录下来的分歧；
- 投票开放时有投票权者的人数；
- 投票人数以及**占有投票权者的比例**——始终公布，包括它很低的情形；
- 各个答案的分布；
- 参与在各国和各地区的分布，其分组方式不允许辨认出个人；
- 任何人自行重新计算结果的方法：投票的公开数据、计票的证明，以及用来验证这一证明的软件。

最后一项是最主要的。**核实不应当要求相信我们。** 一票是秘密的（《宣言》第九条），而核实的构造使它不被揭示：计票的正确性依据公开数据、由公开的软件来证明。我们无法伪造他人的票，而这一点靠的是别人的重新计算；增加一名投票人可以通过在名册中发放记录来实现：每一次发放都在网络中可见，但发放的依据无法从外部核验。

现在的情况如何，我们自己说出来。秘密投票的手段还没有：它正在选定，而二〇二七年二月十七日关于通过《宣言》的投票将秘密进行。在已经部署的公开的投票渠道中，票由钱包签名，投票者的地址是公开的，而投票权由我们的服务器确认；其中没有进行过实质性的测量（[我们现在在哪里](https://earth-lings.org/documents/zh/zh32-where-we-are-now.html)文件）。

### 如果测量被发现有缺陷

选举有重新计票，学术刊物有撤稿。一件仪器如果没有事先宣布的、承认自身错误的程序，它会在第一次出错时失去一切，而错误一定会有。被认定为测量缺陷的有：投票开始之后发现问题的表述具有诱导性或者含义两可；发生故障，致使一部分有投票权的人无法投票或者投了两次；违反问题的形成程序；以及所公布的结果与从名册中读出的结果之间的任何不一致。

此时的程序如下：

1. **任何人都可以提出**，不只是参与者，也不只是我们。提出的申述连同收到的日期一同公布。
2. **是否存在缺陷，不由进行测量的那一方决定。** 如果由进行测量的人作决定，就永远不会有对错误的承认——这是事先就知道的，因此不这样做。
3. **取消在与结果相同的位置、以与结果相同的显著程度公布**，而不是放在脚注里。同时公布缺陷究竟在哪里。
4. **被取消的测量不从编年史中消失。** 它带着取消的标注留在那里。一台可以把过去清理干净的仪器，并不比一台可以修改现在的仪器好多少。
5. **重新测量从头进行**，包括新的对抗阶段。在任何情况下都不得中途修补。
6. **被取消的测量的次数在指标的总列之中公布。** 多年之内这一栏为零，不是值得自豪的理由，而是应当发问的理由。

我们宁愿事先把这些写下来，趁一次测量也还没有进行，程序不会被怀疑是为某个具体的、不方便的情形量身定做的。

## 第十节　什么永远不测量

一台什么都能测量的仪器，早晚会被用来对付某个人。因此各项限制写在《宣言》里，而不是写在细则里，而且它们不由多数人的决定来解除。

**个别国家的内部政治。** 就这类问题根本不形成以全体人民名义作出的集体立场——[《宣言》](https://earth-lings.org/documents/zh/zh01-declaration.html)第五条。Earthlings 人民不参与对国家权力的争夺，不支持政党和候选人，不资助竞选活动，也不号召按某种方式投票。

**具体的人。** 不就具体某个人形成集体立场。人民就现象、决定和制度发表意见，但不就人发表意见。一台对准人的仪器就是一场有程序的私刑，我们不会去建造它。

**不可修改的核心的原则。** 它们不是表决的对象——这不是提高门槛的问题，而是根本不提出的问题。[《宣言》](https://earth-lings.org/documents/zh/zh01-declaration.html)第十一条规定了这些原则的清单；我们在这里不复述它，好让它只有一个来源。为核心增加是可以的，削弱则不可以。

这三项限制使仪器的威力变小。这是自觉的交换：一件不能用来打人的工具，要夺走它困难得多。

## 第十一节　谁为测量付钱

在“谁授权你们”之后，来的是第二个同样危险的问题：**谁为测量付钱。** 答案从别人的经验中已经知道：一家评级机构，如果由它所评价的对象付钱给它，无论工作人员多么诚实，它都会失去可信度——毁掉可信度的是资金流的方向。因此这条规则写在必须执行它的地方：[宪章](https://earth-lings.org/documents/zh/zh05-charter.html)第八条之一和[司库](https://earth-lings.org/documents/zh/zh09-treasury.html)第三十一条之一。

**仪器由人民的共同资金维持。** 参加测量没有、也不设定期的付费：加入时的会费只收一次，覆盖的是身份验证和护照发放的成本。由此得出一个结论：**为了参加测量而付钱，从来都不需要**——而会费由别人代缴的人，拥有的一票与所有人完全一样。无力负担会费的人该怎么办，见[司库](https://earth-lings.org/documents/zh/zh09-treasury.html)和[earthling 之路](https://earth-lings.org/documents/zh/zh14-the-earthling-path.html)两份文件。

**人民从不为委托人的付费而进行测量**——无论是国家、公司还是基金：没有订制的问题，没有花钱插队，也没有付费的表述。

**不接受对测量本身的定向资助。** 即使是不附条件的赠与，只要是针对某个具体问题而取得的，也会造成同样的扭曲：下一个问题会顾及上一次给钱的人而选择。捐赠进入共同资金，不与具体某次测量挂钩。

**测量的支出在共同资金可供公开审计的总报告之中单列一行公布。**

由此得出一个不中听、却诚实的结论：**测量有多少次，取决于人民自己能够负担多少次。** 一台用自己的钱一年做十次测量的仪器，比一台用别人的钱做一百次的仪器更有价值。还有一句保留：共同资金里的钱也是钱，而人民内部的多数同样可能想要一个称心的问题。对于内部的压力，钱的来源根本不提供防护——提供防护的是第七节的问题形成程序和第十节所列的不得测量之物。**把钱与问题分开，消除的是外部的压力，不是内部的。**

# 第四部分　分量的阶梯

## 第十二节　七级台阶

分量不是被授予的，也不是被宣布的。它是一级一级攒起来的。

| 台阶 | 这是什么 | 取决于谁 |
|---|---|---|
| 1. 第一次无法被质疑的测量 | 一个问题，依第九节连同完整的痕迹一并计算并公布。于是出现一种新的产物：不是“调查显示”，而是“这么多经过确认的、唯一的人这样回答了，核实的办法在这里” | 只取决于我们 |
| 2. 第三方的引用 | 文章、报告、新闻报道援引这次测量——因为同类的来源别处没有。这个数字开始不依靠我们而活着 | 一半：无法强迫别人引用，但可以给出理由 |
| 3. 对手使用同一件仪器 | 决定性的门槛，而它与规模无关。**在对立的一方因为我们的测量支持它的论点而援引它的那一天，仪器就不再是我们的，而成了共同的**——要否定它，就不能不否定自己的论据 | 取决于我们的纪律：问题的中立，以及公布对我们不利之物的准备 |
| 4. 征询取代递交 | 某个委员会、某座城市、某个机构请人民就一个问题作测量。渠道不再是对权力的压力，而成了对它的服务；服务不会被取消，人们会习惯它 | 取决于别人 |
| 5. 未答复编年史 | 一份公开的记录：问题提出了，对象是谁，答复收到了还是没有。忽略本身不花什么代价；而带着日期被记下来、年复一年地增长，就有代价了，因为沉默成了事实 | 只取决于我们 |
| 6. 嵌入他人的程序 | 监管机关接受经确认为唯一的人的评论；城市把名册当作抽签的备选池；国际机构把测量纳入磋商程序。忽略变成**在程序上不可能** | 完全取决于别人 |
| 7. 规范 | 磋商先是成为被期待的，随后成为应当的。这不是空想，与土著人民磋商的义务的历史就说明了这一点：从完全不存在，到一九八九年国际劳工组织第169号公约和二〇〇七年的联合国宣言——只用了一代人的时间 | 完全取决于别人 |

## 第十三节　什么取决于我们，什么不取决于我们

**第一、第三和第五级台阶只取决于我们。** 第一次测量、仪器的中立和未答复编年史，都不需要任何人的许可，而且在参与者人数相对不多的时候就能做到。这是我们可以承诺的——因为这是我们自己做的。

**第二级台阶一半取决于我们。**

**第四、第六和第七级台阶取决于别人。** 这些我们不承诺，也不会去承诺。

由此得出一句我们认为是诚实的表述：

> 我们不承诺您会被听见。我们消除的是今天可以正当地不听您的那唯一一个理由。

# 第五部分　界限

## 第十四节　这个声音不做什么

本节之所以存在，是为了让加入的人不要给自己建起我们无法兑现的期待。

**这不是权力。** Earthlings 人民不替国家作决定，也不行使公共权力。它的决定只在它自身内部、并且只对归属于它的人具有拘束力。

**这不代替国籍、选举和法律。** earthling 仍然是自己国家的公民，在它的选举中投票，遵守它的法律，缴纳它的税。归属是补充，而不是替代——[《宣言》](https://earth-lings.org/documents/zh/zh01-declaration.html)第八条。

**这不是政党，也不是参与国内的斗争。** 人民不提名候选人，不支持他们，也不资助他们。无论规模多大。这一限制是创立性的，不得以投票取消。而它不是弱点，是存在的条件：一个由数以千万计的人组成的跨国共同体，如果插手各国的国内政治，头一年就会被禁止，而且禁得有理。

**这不是强制。** 人民说话，但不强制——暴力被排除，没有例外。从测量的结果之中，得不出任何以人民名义宣布的制裁、抵制和惩罚。

**这不取消任何人的权利。** 人民的存在不减少没有加入它的人的权利，也不主张任何领土、任何权力，或者代表全人类说话的权利。

**以及对清醒来说最重要的一点。** 即使人民被完全承认为国际法主体，也不会因此获得改变某个国家法律的可能：没有任何一个主体对另一个主体拥有这样的可能。国际法律人格给予的是**在各主体说话的地方说话的权利**——也就是桌旁的一个位置，而不是对他国议会的权力。凡是许诺别的，都是在许诺做不到的事。

# 第六部分　这给人带来什么

## 第十五节　今天、在增长时、在规模上

**今天**，在参与者数以万计的时候，人得到的东西不多，我们也不会去夸大它：可以验证的“我是一个活着的人，我只有一个，而且任何人都可以核实这一点”、在人民的一切决定中平等的一票，以及参与最初几次测量的可能——也就是身在创造先例的人之中，而不是在使用先例的人之中。最不需要这些的，是制度运转正常的国家里生活优裕的居民：这一切他都已经有了。最需要这些的，是没有一个国家承认他们的人——关于他们见附件[《为什么仪器离不开人民》](https://earth-lings.org/documents/zh/zh02c-why-the-instrument-needs-a-people.html)。

**在增长时**，当参与者数以百万计，需要数量才能出现的东西就出现了：无法被归为边缘现象的测量；不依赖能否使用银行服务的工作与报酬；按不取决于法域的程序解决争议。

**在规模上**，当参与者数以千万计乃至上亿，今天谁也做不到的事情就变得可能：地球上经过验证的人就关系到所有人的问题所形成的、被计算出来的立场。不是带有误差的抽样，也不是一个人可以投一千票的投票，而是被确立并且可核实的事实。据我们所知，这样的产物，国家没有，国际组织没有，民意调查公司也没有：**人们开始把谁算在内，看的不是谁有地位，而是谁手里有别人都没有的东西。**

单说那些还没有出生的人。《宣言》第五条规定：“Earthlings 人民的任何决定，都不应把负面后果转嫁给后代。”该条属于不可修改的核心，也就是根本不付诸表决。由这条规范可以生长出什么、以及它今天为什么在可核实性上比在强制上更有力，见附件[《为什么仪器离不开人民》](https://earth-lings.org/documents/zh/zh02c-why-the-instrument-needs-a-people.html)。

## 第十六节　诚实的不对称

**这里所描述的一切，其价值相对于参与者的人数是非线性的。** 在数以万计时，仪器是一次有意思的试验。在数以千万计时，它是绕不过去的基础设施。造成这一差别的是中间来的那些人，而他们的贡献，比在一切都已经运转起来之后加入的人的贡献要大得多。

由此也得出相反的一面：**早来的参与者承担着做不成的风险。** 他缴纳会费，花时间通过身份验证，参与那些结果可能谁也不感兴趣的投票。我们不知道结局如何，而第十八节列举了可能做不成的原因。我们能够拿来与这一风险相对的，只有它的大小：加入在任何一天都可以撤回，无须说明理由，不要求放弃国籍、国家、语言或者信仰，也不使人负有任何违反本国法律的行为义务。如果做不成，失去的东西不多。

# 第七部分　人民

## 第十七节　人民从何而来

到此为止说的都是仪器。现在说说在这套构造之中人民从何而来，以及它为什么不是装饰。

**人民不是从外面加到仪器上的。如果把对仪器的要求诚实地贯彻到底，它就从里面得出来。**

### 这条路不需要什么

不妨从根本不需要人民的地方说起——否则这个结论看上去会像是硬凑的。不披露身份而验证人的唯一性，不需要人民。按钱包签名进行的可核实投票，不需要。抽签的备选池是一道普通的统计任务。协商小组由国家和大学举办，而且早已办得很好。不止如此：**一个基金会更快、更省钱、遇到的阻力也更小地建起这样一台仪器**——它不必回答关于人民地位的问题，不必用不得持立场的禁令绑住自己的手，也不必向各国解释自己并不主张它们的主权。

这就是说，问题应当提得更准确。不是“没有人民会变得更困难的是什么”，而是**没有人民会变得不可能的是什么**。

### 六个步骤

**第一步。** 需要一次对手也会去核对其计数的测量。由此得出：参与者可核实的唯一性，以及公开的名册。

*人民暂时还不需要。这件事公司也能做。*

**第二步。** 任何测量都是一个分数。分子是谁作了答，分母是谁本来可以作答。没有确定的分母，这个数什么也不说明。

对一项服务来说，分母是“注册用户”。这不是自然的量：它由服务在哪里做广告、在哪里可以使用、放谁进来和不放谁进来所决定。而最要紧的是：**运营者可以移动分母**，招进一些人而不招进另一些人。这不是执行上的缺陷，这是用户群的本性。

由此得出：需要成员身份——一条由人的行为、而不是由运营者的行为划出的界线。

*人民暂时还不需要。社团也有成员身份。*

**第三步。** 运营者不应当有可能影响结果。这就是说，他不能把人纳入构成，不能把人从构成中排除，不能中途改变规则，不能改变问题，也不能不公布不方便的答案。而这恰恰意味着：**参与者对运营者拥有权利。** 而对运营者的权利，只有在存在一份运营者无法改写的文件时才存在。

由此得出：需要的是一份创立文本，不是用户协议。

*人民暂时还不需要。社团也有设立文件。*

**第四步。** 仪器应当比建造它的人活得更久，而且不是可以买到的。可以买到的东西，早晚会被买走，而买主继承了测量的权利。

由此得出：仪器不应当有所有人。这就是说，应当由参与者来治理它。这就是说，这是自治。

**第五步。** 仪器应当对各方同样适用，而不应当是某一国的角色——否则就只有一方使用它，它就变成武器。

由此得出：它不得属于某一个法域，也不得从属于任何一个国家。

*仅有社团已经不够了：它是依一个国家的法律设立的，并从属于该国。*

**第六步。** 最后一步，也是决定性的一步。在公布结果的时候，仪器说的是两句话中的一句：

> “某项服务的多少名用户这样回答了。”
>
> “我们，Earthlings 人民，坚持这一点。”

前一句是数据。后一句是意志。必须答复的是后一句。

现在把这些步骤加起来。一个具有可核实的自愿构成、具有连它自己的运营者都无法触及的创立文本、以自治代替所有人、不属于任何一个国家、并且有能力说“我们”的形成物——**我们提议视为人民。**

这是我们的立场，不是公认的法律检验标准。国际法并未确立这些特征的组合构成人民，我们也不把自己的推理说成是规范。我们主张的只是从这一推导本身看得出来的东西：**这五项特征不是从想要被称作人民的愿望中得出的，而是从对仪器的要求中得出的。** 我们是从什么必须运转出发，走到了一个有名字的东西——而不是反过来。

**人民不是在仪器之前作出的决定。它是仪器如果建造得正确就会抵达的地方。**

### 以及为什么不是社会运动

| | 社会运动 | 人民 |
|---|---|---|
| 构成 | 自称的支持，按其性质不可核实 | 相互承认，而承认是双向的，因而可以计数 |
| 期限 | 到自己的问题解决为止；以胜利或者失败而告终 | 不因某个问题而穷尽，也等不过去 |
| 地理 | 国家层面的；国际的则是各国组织的网络 | 同时在所有法域之中，又不单独在其中任何一个 |
| 法律性质 | 不是自决权的承担者 | 如果各项特征得到确立，就是承担者；问题悬而未决 |

这里说的是社会运动。民族解放运动属于另一个法律范畴：它们的地位是在非殖民化之中形成的，而它们得到承认，恰恰是作为代表行使自决的人民发言的一方。上面三行不取决于第四行的结局如何。

### 五个理由，各属一类

上面的推导是一个论证。下面是五个各自独立的论证：即使推导有错，它们仍然成立。这五个论证的详细分析见附件[《为什么仪器离不开人民》](https://earth-lings.org/documents/zh/zh02c-why-the-instrument-needs-a-people.html)。

**第一。意志无法被测量——它只能被产出。** 并不存在一个放在某处、等着被测的“人类想要什么”。意见可以不靠人民来测量；**意志不靠人民则产不出来。** 而人们忽略的是意见，答复的是意志。

**第二。“谁授权你们发问”这个问题。** 只要测量开始有分量，这个问题头一天就会响起。国家的回答是：法律。公司的回答是：没有人，而它也不主张自己有分量。基金的回答是：董事会——而接下来的“那么是谁选出了董事会”就结束了这场对话。人民的回答是：它的参与者，按照每个人都可以核实的程序。**只有两个回答经得起第二个问题。**

**第三。不可修改的核心是对仪器免遭夺取的防护，而不只是伦理。** 一票不得被购买——这就是说，测量的结果无法被买下；受托事项不变成职务——这就是说，维护仪器的人无法从内部把它夺走；退出自由而开除并不存在——这就是说，分母无法被清理掉不方便的人。属于某个基金的仪器，代替这些的是理事会的诚信，而诚信是不继承的。

**第四。谁来回答第四十个问题。** 一次回答的收益接近于零，付费的回答会使测量贬值，强制已被核心排除。剩下的是归属：**一台靠自愿参与运转数十年的仪器，需要的不是动机，而是归属**，而这个理由是工程上的，不是诗意上的。

**第五，法律上的。** 分量的阶梯上面那几级，能够走上去的是“某个人”，而不是“某个东西”：在国际法上作为一方的是主体，而自决权是属于人民的。这句保留我们立刻重复：它是否适用于自愿创立的非领土人民，国际法没有确定，我们也不作这样的主张。但基金根本没有机会，而人民的机会并没有关闭。

对这一推理的现场检验已经有了：最大的一个不靠人民建成的人的唯一性验证项目，两年之内在三个国家收到了监管机构的限制性决定，而它的名册被当作具有公共意义的测量的来源加以使用的情形，我们一例也不知道。这个案例见附件[《为什么仪器离不开人民》](https://earth-lings.org/documents/zh/zh02c-why-the-instrument-needs-a-people.html)。

### 人民的代价是什么

既然要诚实，就把代价也说出来。增长更慢：加入人民比注册困难。所提出的东西更难解释。一个悬而未决的法律问题，对方正好拿它做文章。国家的戒备，而基金本来不会遇到。还有自愿承担的限制，这些是基金本来不会给自己加上的。这一交换是自觉作出的，而它可能并不划算。

### 怎样检验我们是错的

按照本文件其余部分的精神，我们说出自己出错的条件。如果十年之后，某个基金或者公司的可核实调查被条约机构和国家定期引用，而且没有人问“谁授权你们”——那就说明人民是多余的，而我们在便宜的路管用的地方选了昂贵的路。

### 以及相反的问题

人民要仪器做什么？没有仪器的人民，是一份关于意向的声明，却没有表达共同意志的办法：正是我们自己所抱怨的那种情形。没有人民的仪器，是一些数据，却没有人能以谁的名义把它们提出来。**这不是可以丢掉其中一个的两件东西。这是同一件东西的两半。** 没有相互承认的可核实性给出的是统计；没有可核实性的相互承认给出的是请愿书。合在一起，它们给出的是至今还不曾有过的东西。

# 第八部分　什么可能出错

## 第十八节　这件事落空的九种方式

本节不是为了平衡而写的。所列的每一种结局都可能发生，其中有些比好的结局更可能。完整的分析见附件[《为什么仪器离不开人民》](https://earth-lings.org/documents/zh/zh02c-why-the-instrument-needs-a-people.html)；这里每一种方式只占一行。

| 方式 | 我们在做什么 | 我们不保证什么 |
|---|---|---|
| **1. 党派性。** 人民或者它相当一部分人站到别人国内分裂的某一方去，于是对一半社会来说，仪器成了对手的武器 | 不得就国内政治持立场的禁令写在《宣言》里，而不是写在细则里 | 不保证参与者以自己名义发表的言论不会被算到人民头上 |
| **2. 为了答案而拟定的问题。** 表述结果带有诱导性，于是一切测量——过去的和将来的——都落入怀疑 | 拟定者与管理者分离，提前公布，对抗阶段，开始之后不得修改 | 不保证在答案对某个很有力的人非常重要时，程序还顶得住 |
| **3. 投票率低。** 人民有一亿参与者，而参加测量的只有百分之三 | 下面另行说明：这是首要的风险 | |
| **4. 浅表化。** 测量变成民意调查：十秒钟里几百万个回答，不把问题弄清楚 | 第八节的双层结构 | 不保证能把审议小组组织起来，也不保证准备好的方案会有人读 |
| **5. “外国干涉”这一框架。** 跨国共同体被宣布为他国影响的工具 | 人民不就各国的国内问题持立场，提供的是工具，而不是意见 | 什么也不保证。这个决定不由我们作出 |
| **6. 名册被看作威胁，而不是资源** | 原始生物特征不予保存，可辨认身份的数据不存放在名册中，通过验证也没有报酬 | 不保证这样就够了 |
| **7. 仪器从内部被夺取。** 问题的挑选、时机和解释集中到在意结果的人手里 | 以抽签代替任命，受托事项可撤回，全部痕迹公开 | 不保证防护是绝对的。它不是 |
| **8. 使人变质的成功。** 影响开始显得太珍贵，不值得为中立去冒险 | 无论内容如何都必须公布结果的义务。出事的征兆从外面看得见：测量不再带来不中听的答案 | 不保证这种诱惑不会出现：它出现在的不是坏人身上，而是珍惜已有成果的人身上 |
| **9. 没有人来问。** 仪器运转得无可挑剔，却没有人使用它。这是坏结局之中最可能的一种：它不需要敌意，冷漠就够了 | 未答复编年史把沉默变成被记录下来的事实。它起效很慢，而且可能根本不起效 | 什么也不保证。无法强迫别人使用 |

**投票率低单独说，因为按重要性它是第一位的。** 投票率低的测量**比没有测量更糟**：它不增添证明，反而损害已经积累起来的东西。它不靠提醒、也不靠号召来医治，而靠问题：人在问题关系到他的生活、而且回答能起作用的时候才作答（第七节）。投票率始终并且首先公布，包括很低的数值，而**投票率是本项目最重要的生命指标，比参与者的人数更重要**：一个由一千万人构成、投票率百分之四十的人民共同体，其分量远远超过一个由一亿人构成、投票率百分之四的人民共同体，尽管两种情形下作出回答的人一样多——都是四百万。我们不保证合适的问题总能找到：界线是有意画窄的，我们也不会为了投票率去拓宽它。

# 第九部分　可核实性

## 第十九节　所描述的东西哪些已经有了，哪些还没有

已经建成并在运转的有：身份验证与不可转让护照的发放、区块链上的护照名册、公开的投票渠道和链上的共同资金。对本文件来说最要紧的东西还没有建成：**实质性的测量一次也没有进行过**，详细的问题形成程序并不存在，抽签选出的审议小组没有，未答复编年史尚未开设，独立的安全审计也不曾做过。

已经建成什么、哪些是封闭的、今天在哪些地方还得相信我们，其完整并且始终最新的清单见[我们现在在哪里](https://earth-lings.org/documents/zh/zh32-where-we-are-now.html)文件。事实应当只有一个来源，而那就是它。

## 第二十节　应当据以评判我们的指标

为了让这里所描述的东西可以被核实，而不是被当作信条接受，我们说出应当据以评判我们的指标。[宪章](https://earth-lings.org/documents/zh/zh05-charter.html)第八条之一规定了公布投票人数占有投票权者的比例这项义务；其余的指标本文件并不设定，也无法设定——它把它们作为一把尺子提出来，并且把这把尺子对准自己。其中没有一项是宣传性的，而且头几年我们在其中若干项上必定会显得很难看。

| 指标 | 为什么是它 |
|---|---|
| 每次测量中投票人数占有投票权者的比例 | 最主要的指标。始终公布，包括低值 |
| 参与在各国和各地区的分布 | 由一个国家构成的人民不具有全球性 |
| 经过对抗阶段的问题的比例，以及提出的异议数 | 显示针对“为答案而设问”的防护是否起作用 |
| 结果与提问者的预期相反的测量次数 | 一台总是印证预期的仪器是坏的 |
| 结果在人民内部改变了什么的投票的比例 | 显示与全球性问题并列的，是否有后果确定发生的问题 |
| 未答复编年史：提出多少、答复多少、未答复多少 | 把沉默变成事实 |
| 第三方引用的次数及其构成 | 第二级台阶到来了没有 |
| 测量被这样一方援引的次数：它对该方有利，而与我们的立场相反 | 第三级台阶的唯一指标 |

## 这里没有什么

**这里没有期限。** 没有哪一级台阶写着“三年之后”：速度由参与者的人数、积累起来的实践和别人的决定所决定，不由我们的计划决定。期限属于别的东西：创立期定于二〇二六年十月二十二日开始，《宣言》将付诸表决（[创立期](https://earth-lings.org/documents/zh/zh20-the-founding-period.html)）。

**这里没有对结果的承诺。** [《宣言》](https://earth-lings.org/documents/zh/zh01-declaration.html)第六条规定了人民受什么约束、不受什么约束，这里我们不再复述，以使规范只保留一个来源。简而言之：承认不在它的权力之内，而人民的存在不取决于承认。
