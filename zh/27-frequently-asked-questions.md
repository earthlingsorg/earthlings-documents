# 常见问题

**正在决定是否加入的人、以及已经加入的人所关心的实际问题**

> **这是一份什么文件。** 这里对问得最多的问题给出简短的回答，并指出完整的答复在哪里。它不确立任何东西，也不创设任何规则：规则在 [Earthlings 宪章](https://earth-lings.org/documents/zh/zh05-charter.html) 和 [Earthlings 宣言](https://earth-lings.org/documents/zh/zh01-declaration.html) 里，凡有不一致，以它们为准。在创立期——自二〇二六年十月二十二日起至《宣言》通过之时止——签署《宣言》和加入人民都已暂停：由已通过的文本所确定的人民还不存在。这一期间的身份验证免费进行，验证完成后发给创立的参与者一份临时证件，而不是护照（《创立期》文件，第二部分第 5 点）。临时证件在与护照相同的合约中发放（《我们现在在哪里》文件）。关于加入、会费和护照的答复，描述的是《宣言》通过之后开始的基本制度。
>
> 法律上的反对意见——关于自决、法律人格和承认——另有专门文件详细讨论，其中也摆出了反对我们的论据：[反对意见与答复](https://earth-lings.org/documents/zh/zh26-objections-and-answers.html)。

# 一、金钱与参与

### 七十九美元是为什么收的，这笔钱又去了哪里？

会费用于支付身份验证和发放 Earthlings 护照的成本，并支持人民的基础设施。它进入共同资金，按公布的份额分配：平台百分之二十五，增长与传播百分之三十，社区项目百分之二十，教育百分之十五，储备百分之十。

归属不是会费买来的：它因签署《宣言》而产生。

→ [司库](https://earth-lings.org/documents/zh/zh09-treasury.html)

### 以后还会有别的付款吗？

不会。会费是一次性的：拿到护照之后，既不存在按年缴纳的付款，也不存在按月缴纳的付款。

→ [earthling 之路](https://earth-lings.org/documents/zh/zh14-the-earthling-path.html)

### 如果我付不起呢？

那么在加入需要缴纳会费时，您可以进入公开的排队，会费可以由另一个人或者司库代您缴纳；对此没有保证。付款这一步将有第二个按钮——“我需要会费”：它什么也不会问，将把您排进一个公开的队列，队列里只看得到编号和日期。任何人都可以为这个队列付款，但不得挑选替谁付——付的永远是排在最前面的那一位。如果有人替您交上了会费，您拿到的护照将与所有人的完全一样：名册里不记录是谁为它付了钱。等待护照的发放是免不了的，而要等多久，事先无从知道。对人民的归属并不取决于此：归属因签署《宣言》而产生，而不是因会费而产生。更详细的说明见 [earthling 之路](https://earth-lings.org/documents/zh/zh14-the-earthling-path.html) 这份文件。

→ [earthling 之路](https://earth-lings.org/documents/zh/zh14-the-earthling-path.html)

### 我没有时间，也没有意愿积极参与。加入还有意义吗？

有。拿到护照之后不存在强制性的活动：可以做参与者而不花时间，以后再投入，也可以始终不投入。

被动的参与也是完整的参与。加入本身就使人民的人数增加，人民共同的声音也随之更有分量——这已经是一份贡献。积极参与通常来得晚一些，是在人看到别人的参与确实带来结果之后。

如果您很长时间什么都不做，状态会转为不活跃：投票权此时**完全保留**；不活跃的 earthling 不计入据以计算法定人数的人数，以免为其余的人抬高要求，而只要做出第一个动作，状态即行恢复。

→ [宪章第二十条](https://earth-lings.org/documents/zh/zh05-charter.html)

### 我的国籍和纳税会怎么样？

不会有任何变化。国籍、税收和司法管辖都不受影响。earthling 护照不给予任何签证权利，不替代您所在国家的证件，在国家机关里也不具有效力。

→ [SBT 护照](https://earth-lings.org/documents/zh/zh15-sbt-passport.html)

# 二、认同与数据

### 关于我，你们保存什么？

真实的姓名、证件号码和生物特征图像**不保存**。我们保存的是：化名、邮箱地址、国家、年满十八岁的确认和钱包地址，以及《隐私政策》中列举的技术数据和使用平台的数据。

身份验证之后留下的是验证的状态、证件的种类和签发国家、验证的数值评分、拒绝的理由，以及以服务器的秘密密钥计算出的不可逆哈希值——证件号码的哈希值，以及证件上名的哈希值、姓的哈希值和出生日期的哈希值；保存这些哈希值唯一的用途，是使同一个人不可能持有两本有效的护照。

→ [生物特征验证政策](https://earth-lings.org/documents/zh/zh16-biometric-verification.html)

### 一定要用真实姓名吗？

为了验证——是的：与证件上一致的姓与名，用于与证件核对。其他参与者看到的是您选择的化名；在公开的护照查验中没有它。证件数据只在验证的那一刻被核对；验证之后，从中留下的只有证件的种类和签发国家以及不可逆的哈希值。

→ [生物特征验证政策](https://earth-lings.org/documents/zh/zh16-biometric-verification.html)

### 如果数据泄露了呢？

真实的姓名、证件号码和图像我们这里没有：能泄露出去的只有手里已经有的东西。发生泄露时，可能受到影响的是邮箱地址、化名、国家、钱包地址、技术数据和使用平台的数据，而从验证留下的是它的结果和不可逆的哈希值。哈希值不可逆，并且以服务器的秘密密钥计算：从它读出姓名或者证件号码是做不到的，没有密钥也无法用穷举去猜出它们。事件通知在七十二小时之内发出。

→ [隐私政策](https://earth-lings.org/documents/zh/zh28-privacy-policy.html)

### 你们会把数据交给国家吗？

只有依据已经生效的法院判决，或者与之相当的合法要求，才会交出，而每一次都要核查这一要求的合法性。参与者会就此得到通知，除非判决禁止通知。

→ [生物特征验证政策](https://earth-lings.org/documents/zh/zh16-biometric-verification.html)

### 退出的时候会发生什么？

退出只能是自愿的，也无须说明理由：提出申请，七十二小时用于确认（这一暂缓可以放弃），然后**由您本人用自己的密钥销毁护照**。服务器不保存您的密钥，也无法阻拦；任何人都无权代您销毁护照，但在合约所有者的权限尚未移交给多重签名之前，护照的发放与销毁在技术上仍由一把密钥掌握（《我们现在在哪里》文件）。

销毁护照本身并不删除数据：账户数据依您的要求删除。不可逆的哈希值以假名化的形式保存下来，唯一的目的是使同一个人不可能持有两本有效的护照。记账单位仍然属于您。任何时候都可以回来。

→ [earthling 之路](https://earth-lings.org/documents/zh/zh14-the-earthling-path.html)

# 三、权力与治理

### 我会被开除吗？

不会。在任何情况下、对任何多数而言，都不存在开除的程序。

**也不得因为您的观点而夺走您的一票。** 不因为您如何投票，不因为您不同意某项决定，也不作为违反规则的一般惩罚。针对个人的措施仅有一项——警告，而它不剥夺任何权利：既不剥夺一票和归属，也不剥夺提出建议的权利、创建蜂巢单元（小型工作组）并加入它们的权利、使用各项服务的权利以及其他一切权利。其余的措施针对的是项目或者蜂巢单元，而不是个人。

唯一的例外是对投票机制本身经过证实的攻击：串通、买票或卖票、胁迫他人、试图再办一本护照。此时一票最长中止六个月，由百分之七十五的多数以无记名方式决定，并保留申辩的权利和申诉的途径。观点在任何时候都不构成理由。

→ [宪章第十七条和第二十二条](https://earth-lings.org/documents/zh/zh05-charter.html)

### 究竟是谁在治理？

《宣言》通过之后，作出决定的唯一机关是 DAO 全体大会，也就是全体参与者。在创立期内，在文本方面唯一的裁量权限，是《宣言》作者关于把建议纳入文本的决定（《创立期》文件，第二部分第 2 点）；《宣言》的作者、项目的创立者，此外没有任何特别的权利（在通过之前还得把他当作创立者来相信的地方——共同资金和名册合约所有者的密钥——写在《我们现在在哪里》文件之中）：创立的参与者的临时证件违背持有人意愿被销毁时，他只依同一份文件的封闭根据进行（第二部分第 5 点）。

目前处在过渡期，这一点是公开承认的：一部分职能暂时以程序方式履行，共同资金的密钥在创立者手里（它的钱包上签名门槛目前为一），而把共同资金的密钥移交给多重签名，是路线图各阶段之间过渡的标准。但即便在创立期内，创立者也无权修改《宣言》（依这一时期的公开程序纳入建议的情形除外），无权剥夺任何人的地位，无权把共同的资金用于私人目的，也无权阻挡去中心化。

→ [路线图](https://earth-lings.org/documents/zh/zh19-roadmap.html)

### 什么能阻止一个小团体夺取治理权？

夺取需要积累，而这里没有可以积累的东西：一票与一个经过验证的人一一对应，不得被购买，也不从金钱、声望或职务中产生。不可修改的核心置于任何投票之外。

这里没有一个自己会变成主人的守护者，取而代之的是带着名册离开的权利：护照及其记录存放在公开的网络上，而不在我们的服务器上，因此《宣言》通过之后对平台的夺取是可以扭转的：如果由于治理被夺取、基础设施停止运行或者其他情形，《宣言》的实施变为不可能，经确认的 earthlings 可以依据同一份名册，在另一种技术基础或者组织基础上把人民延续下去（《宣言》第十一条）；新的平台按公布的规则建造，而平台和身份验证的代码是封闭的，因为它处理个人数据。关于签署《宣言》的记录，以及据以检验一个人唯一性的哈希值，并不存放在名册之中，而是存放在我们的服务器上，因此新的平台得自己建起自己的身份验证（《我们现在在哪里》文件）。今天夺取所能得到的好处并不是零：只要合约所有者的权限尚未移交给多重签名，而共同资金的门槛还是一个签名，夺得这些密钥的人就能在同一份名册中发放和销毁记录，并处分共同资金（《我们现在在哪里》文件）。

→ [路线图，第 07 节](https://earth-lings.org/documents/zh/zh19-roadmap.html)

### 独立理事会是不是一个影子参议院？

不是。它的结论只有建议性质：它不得阻止决定，没有否决权，不参与财务，甚至不得推迟把问题交付表决。撤换它的成员只能依据明确指出的理由，而不同意它的立场不属于这样的理由。

理事会目前尚未组成。

→ [独立理事会](https://earth-lings.org/documents/zh/zh11-independent-council.html)

# 四、伦理与立场

### 这是不是一个教派？

教派是出不去的。从这里退出只是一个动作，用您自己的密钥完成，谁也无法阻拦，创立者也不例外。理由不必说明。

人与人之间不存在支配权力：没有人处于高于另一个人的地位，协调人在任何时候都可以被撤换，批评是一项权利，而不是过错。价值列举于《宣言》第三条：其中最高的是生命；其余的有自由、尊严、全球团结、对地球的关照。您的信仰、观点和生活方式，这里不过问。

### 这是不是加密货币？会有人靠它赚钱吗？

一票不得被购买，也不取决于金钱——这是不可修改的规则。区块链用在需要一份无法在不被察觉的情况下更改的记录的地方：护照和共同资金。使亲自投出的一票保持秘密的投票手段还在选定之中（《我们现在在哪里》文件）。

记账单位今天没有发行，也不在任何地方交易：参与经济记在内部的账上。将来在交易所上市是可能的，但没有被承诺过，也不是目标；至于价值上涨，任何人在任何情形下都不作承诺。

→ [Earthlings Coin](https://earth-lings.org/documents/zh/zh10-earthlings-coin.html)

### 你们与其他 DAO 有什么不同？

基础设施是同一套，装作不是这样没有意义。区别在于它连接到什么上面。

以往的尝试都折在三件事上。一枚代币一票：谁的钱多，谁说了算。没有身份验证：一个人用许多钱包投票。没有不可修改的基础：投票规则本身成了投票的对象。

在这里，一票与一个经过验证的活人相连，不取决于余额；记账单位无论数量多少都不带来投票权；组织不得成为参与者；而归属、平等的一票、退出的权利和价值，则完全置于投票之外。

这一制度是否经受住了规模的检验——没有。我们只是说：以往失败的原因已经被指出来，对它们的回答已经写进了制度本身。

→ [反对意见与答复](https://earth-lings.org/documents/zh/zh26-objections-and-answers.html)

### 关于我的决定是由人工智能作出的吗？

身份验证由自动系统完成，它的拒绝不是最终的：您有权要求由人复核，而在两次自动尝试不成功之后，由人复核无须另行请求即行进行。如果分析建议和项目申请时使用了辅助工具，它们并不作决定：它们的结论只有建议性质，而依据会被公开。

→ [数字平台](https://earth-lings.org/documents/zh/zh12-digital-platform.html)

### 这件事将来会得到法律上的承认吗？

没有什么可等的，也没有谁可等：并不存在一种能够把自愿的非领土共同体承认为人民的程序，也没有人民的总名册。现有的程序——联合国非自治领土清单、各国承认土著人民的程序——依据的要么是领土，要么是某一个国家的国内法，而我们这样的共同体一个也走不通。

另有一样东西。法律上的可识别性——就是在出现具体问题的地方，人民被当作人民来对待：在各种平台上，在协商中，在争议处理中。它靠实践、时间、参与人数和法律工作累积起来，这四样都取决于我们，而不取决于别人的机关。快还是慢，没有人作承诺；反对我们的论据已经不加缓和地讨论过。

→ [反对意见与答复](https://earth-lings.org/documents/zh/zh26-objections-and-answers.html)

### 现在真正在运转的是什么，还没有的是什么？

已经在运转的有：身份验证、护照、平台、蜂巢单元体系。共同资金放在 Safe 钱包上，它的交易是公开的，任何人都可以按地址查验。

暂时还没有运转的有：实质性的投票不曾举行过；司库的智能合约——不经中介执行决定的程序——尚未部署；记账单位尚未发行。共同资金的钱包上还没有多重签名：签名门槛为一，密钥在创立者手里，这一点按地址就能看到。把共同资金的密钥移交给选出的 Core Nodes 的多重签名或者移交全体大会控制，是路线图各阶段之间过渡的标准。Core Nodes 和 Emergency Multisig——受托负责技术支持和紧急响应的人——尚未选出，独立理事会也尚未组成。

→ [路线图](https://earth-lings.org/documents/zh/zh19-roadmap.html)
