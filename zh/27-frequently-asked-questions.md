# 常见问题

**正在决定是否加入的人、以及已经加入的人所关心的实际问题**

> **这是一份什么文件。** 这里对问得最多的问题给出简短的回答，并指出完整的答复在哪里。它不确立任何东西，也不创设任何规则：规则在 [Earthlings 宪章](https://earth-lings.org/documents/zh/zh05-charter.html) 和 [Earthlings 宣言](https://earth-lings.org/documents/zh/zh01-declaration.html) 里，凡有不一致，以它们为准。
>
> 法律上的反对意见——关于自决、法律人格和承认——另有专门文件详细讨论，其中也摆出了反对我们的论据：[反对意见与答复](https://earth-lings.org/documents/zh/zh26-objections-and-answers.html)。

# 一、金钱与参与

### 七十九美元是为什么收的，这笔钱又去了哪里？

会费用于支付身份验证和签发 Earthlings 护照的成本，并支持人民的基础设施。它进入共同资金，按公布的比例分配：平台百分之二十五，增长与传播百分之三十，社区项目百分之二十，教育百分之十五，储备百分之十。

归属不是会费买来的：它因签署《宣言》而产生。

→ [司库](https://earth-lings.org/documents/zh/zh09-treasury.html)

### 以后还会有别的付款吗？

不会。会费是一次性的：拿到护照之后，既不存在按年缴纳的付款，也不存在按月缴纳的付款。

→ [earthling 之路](https://earth-lings.org/documents/zh/zh14-the-earthling-path.html)

### 如果我付不起呢？

那就由别人替您把会费交上。在付款这一步有第二个按钮——“我需要会费”：它什么也不问，只把您排进一个公开的队列，队列里只看得到编号和日期。任何人都可以为这个队列付款，但不得挑选替谁付——付的永远是排在最前面的那一位。您拿到的护照与所有人的完全一样：名册里不记录是谁为它付了钱。等待是免不了的，但金钱不会把入口永远关上。更详细的说明见 [earthling 之路](https://earth-lings.org/documents/zh/zh14-the-earthling-path.html) 这份文件。

→ [earthling 之路](https://earth-lings.org/documents/zh/zh14-the-earthling-path.html)

### 我没有时间，也没有意愿积极参与。加入还有意义吗？

有。拿到护照之后不存在强制性的活动：可以做参与者而不花时间，以后再投入，也可以始终不投入。

被动的参与也是完整的参与。加入本身就使人民的人数增加，人民共同的声音也随之更有分量——这已经是一份贡献。积极参与通常来得晚一些，是在人看到别人的参与确实带来结果之后。

如果您很长时间什么都不做，状态会转为不活跃：投票权此时**完全保留**，并在您做出第一个动作时恢复，只是您的一票不再计入法定人数，以免抬高对其他人的要求。

→ [宪章第二十条](https://earth-lings.org/documents/zh/zh05-charter.html)

### 我的国籍和纳税会怎么样？

不会有任何变化。国籍、税收和司法管辖都不受影响。earthling 护照不给予任何签证权利，不替代您所在国家的证件，在国家机关里也不具有效力。

→ [SBT 护照](https://earth-lings.org/documents/zh/zh15-sbt-passport.html)

# 二、认同与数据

### 关于我，你们保存什么？

真实的姓名、证件号码和生物特征图像**不保存**。名册里只有化名、邮箱地址、年满十八岁的确认、国家和验证状态。

另外，在一个隔离的系统里保存着不可逆的密码学哈希值——唯一的用途是使同一个人无法持有两本有效的护照。

→ [生物特征验证政策](https://earth-lings.org/documents/zh/zh16-biometric-verification.html)

### 一定要用真实姓名吗？

不必。对外的名字是您自己选择的化名。证件数据只在验证的那一刻被核对，之后即被删除。

→ [生物特征验证政策](https://earth-lings.org/documents/zh/zh16-biometric-verification.html)

### 如果数据泄露了呢？

真实身份与化名之间的关联不保留：能泄露出去的只有手里已经有的东西。能被窃取的是加密的不可逆哈希值，从中既得不到图像，也得不到证件数据。存储彼此分离，加密采用 AES-256，事件通知在七十二小时之内发出。

→ [隐私政策](https://earth-lings.org/documents/zh/zh28-privacy-policy.html)

### 你们会把数据交给国家吗？

只有依据已经生效的法院判决，或者与之相当的合法要求，才会交出，而每一次都要核查这一要求的合法性。参与者会就此得到通知，除非判决禁止通知。

→ [生物特征验证政策](https://earth-lings.org/documents/zh/zh16-biometric-verification.html)

### 退出的时候会发生什么？

退出只能是自愿的，也无须说明理由：提出申请，七十二小时用于确认（这一暂缓可以放弃），然后**由您本人用自己的密钥销毁护照**。服务器不保存您的密钥，既不能代您完成，也无法阻拦。

数据与身份之间的关联被切断，个人数据的处理随之停止。记账单位仍然属于您。任何时候都可以回来。

→ [earthling 之路](https://earth-lings.org/documents/zh/zh14-the-earthling-path.html)

# 三、权力与治理

### 我会被开除吗？

不会。在任何情况下、对任何多数而言，都不存在开除的程序。

**也不得因为您的观点而夺走您的一票。** 不因为您如何投票，不因为您不同意某项决定，也不作为违反规则的一般惩罚。五个等级的限制涉及的是参加蜂巢单元——小型工作组——的资格、提出建议的权利和使用服务的权限，而不是一票，也不是归属。

唯一的例外是对投票机制本身经过证实的攻击：串通、买票或卖票、胁迫他人、试图再办一本护照。此时一票最长中止六个月，由百分之七十五的多数以无记名方式决定，并保留申辩的权利和申诉的途径。观点在任何时候都不构成理由。

→ [宪章第十七条和第二十二条](https://earth-lings.org/documents/zh/zh05-charter.html)

### 究竟是谁在治理？

作出决定的唯一机关是 DAO 全体大会，也就是全体参与者。创立者没有任何特别的权利。

目前处在过渡期，这一点是公开承认的：一部分职能暂时以程序方式履行，共同资金的密钥在创立者手里，交出这些密钥是进入下一阶段的标准。但即便是现在，创立者也不得修改《宣言》，不得剥夺任何人的地位，不得把共同的资金用于私人目的，也不得阻挡去中心化。

→ [路线图](https://earth-lings.org/documents/zh/zh19-roadmap.html)

### 什么能阻止一个小团体夺取治理权？

夺取需要积累，而这里没有可以积累的东西：一票与一个经过验证的人一一对应，不得被购买，也不从金钱、声望或职务中产生。不可修改的核心置于任何投票之外。

这里没有一个自己会变成主人的守护者，取而代之的是带着名册离开的权利：护照及其记录存放在公开的网络上，而不在我们的服务器上，因此人民可以离开被夺取的平台，什么也不留在里面，夺取所能得到的好处归于零。社区可以依照公布的规则，针对同一份名册建设新的平台；与此同时，平台和身份验证的代码是封闭的，因为它处理个人数据。

→ [路线图，第 07 节](https://earth-lings.org/documents/zh/zh19-roadmap.html)

### 独立理事会是不是一个影子参议院？

不是。它的结论只有建议性质：它不得阻止决定，没有否决权，不参与财务，甚至不得推迟把问题交付表决。撤换它的成员只能依据明确指出的理由，而不同意它的立场不属于这样的理由。

理事会目前尚未组成。

→ [独立理事会](https://earth-lings.org/documents/zh/zh11-independent-council.html)

# 四、伦理与立场

### 这是不是一个教派？

教派是出不去的。从这里退出只是一个动作，用您自己的密钥完成，谁也无法阻拦，创立者也不例外。理由不必说明。

权力不集中在任何一点上，协调人在任何时候都可以被撤换，批评是一项权利，而不是过错。价值的内核是最小限度的：尊严、自由、团结。您的信仰、观点和生活方式，这里不过问。

### 这是不是加密货币？会有人靠它赚钱吗？

一票不得被购买，也不取决于金钱——这是不可修改的规则。区块链只用在需要一份无法伪造的记录的地方：护照、投票、共同资金。

记账单位今天不在任何地方交易，只服务于内部流转。将来在交易所上市是可能的，但没有被承诺过，也不是目标；至于价值上涨，任何人在任何情形下都不作承诺。

→ [Earthlings Coin](https://earth-lings.org/documents/zh/zh10-earthlings-coin.html)

### 你们与其他 DAO 有什么不同？

基础设施是同一套，装作不是这样没有意义。区别在于它连接到什么上面。

以往的尝试都折在三件事上。一枚代币一票：谁的钱多，谁说了算。没有身份验证：一个人用许多钱包投票。没有不可修改的基础：投票规则本身成了投票的对象。

在这里，一票与一个经过验证的活人相连，不取决于余额；记账单位无论数量多少都不带来投票权；组织不得成为参与者；而归属、平等的一票、退出的权利和价值，则完全置于投票之外。

这一制度是否经受住了规模的检验——没有。我们只是说：以往失败的原因已经被指出来，对它们的回答已经写进了制度本身。

→ [反对意见与答复](https://earth-lings.org/documents/zh/zh26-objections-and-answers.html)

### 关于我的决定是由人工智能作出的吗？

不是。辅助工具帮助完成申请的初步核查和数据分析，但作决定的是人。任何自动得出的结论都只有建议性质，它的依据会被公开，而只要您提出要求，就保证由人重新审查。

→ [数字平台](https://earth-lings.org/documents/zh/zh12-digital-platform.html)

### 这件事将来会得到法律上的承认吗？

没有什么可等的，也没有谁可等：承认人民的机关对谁都不存在。人民的名册并不存在，任何人民——库尔德人、巴勒斯坦人、萨米人——都没有走过确认自身存在的程序。

另有一样东西。法律上的可识别性——就是在出现具体问题的地方，人民被当作人民来对待：在各种平台上，在协商中，在争议处理中。它靠实践、时间、参与人数和法律工作累积起来，这四样都取决于我们，而不取决于别人的机关。快还是慢，没有人作承诺；反对我们的论据已经不加缓和地讨论过。

→ [反对意见与答复](https://earth-lings.org/documents/zh/zh26-objections-and-answers.html)

### 现在真正在运转的是什么，还没有的是什么？

已经在运转的有：身份验证、护照、平台、蜂巢单元体系。共同资金放在 Safe 钱包上，它的交易是公开的，任何人都可以按地址查验。

暂时还没有运转的有：实质性的投票不曾举行过；司库的智能合约——不经中介执行决定的程序——尚未部署；记账单位尚未发行。共同资金的钱包上还没有多重签名：签名门槛为一，密钥在创立者手里，这一点按地址就能看到。转为由六名选出的签署人组成的多重签名，是路线图各阶段之间过渡的标准。Core Nodes 和 Emergency Multisig——受托负责技术支持和紧急响应的人——尚未选出，独立理事会也尚未组成。

→ [路线图](https://earth-lings.org/documents/zh/zh19-roadmap.html)
